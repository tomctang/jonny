PE 142#

  • Euclid’s formula

    • \(a^2+b^2=c^2\)

    • \(a=m^2-n^2\)

    • \(b=2mn\)

    • \(c=m^2+n^2\)

    • We also need to fix this by including non-primitive triplets

  • First we find \(x,y\) such that \(x+y\) and \(x-y\) are perfect squares.

    • Using a pythagorean triple, \(m^2,n^2\) are squares.

    • \(n^2=\frac{c-a}2\)

    • \(m^2=\frac{a+c}2\)

    • Let \(m^2=x+y\) and \(n^2=x-y\).

    • \(c=2x\),\(x=\frac c2\)

    • \(a=2y\),\(y=\frac a2\)

    • This can become a problem though, because calculating non-primitive triplets using euclid’s formula takes too long.

  • To avoid using pythagorean triplets, we can iterate through possible squares to compress the search space.

    • We have to let the squares encode the info for \(x,y,z\).

    • \(a^2=x+y\) and \(b^2=x-y\) means we can find \(x,y\).

    • \(c^2=x+z\) because a combination of \(z\) with \(x\) or \(y\) works.

    • We should increment \(a\) by \(2\) given \(b\) because \(a,b\) have the same integer parity(otherwise \(x,y\) not integer).

    • We can also let \(d,e,f\) represent the remaining \(3\) squares to derive more relations such as parity.

    • \( \mathcal{S} = \left\{ (x, y, z) \in \mathbb{Z}^3 \;\middle|\; \begin{array}{l} \exists a, b, c \in \mathbb{Z} \text{ such that} \\ 1 \le b < L \\ b < a < L, \quad a \equiv b \pmod 2 \\ x = \frac{a^2 + b^2}{2}, \quad y = \frac{a^2 - b^2}{2} \\ \lfloor \sqrt{x} \rfloor < c < a \\ z = c^2 - x \\ c^2 - b^2 = \square \\ a^2 - c^2 = \square \\ a^2 + b^2 - c^2 = \square \end{array} \right\} \)

      • Let \(\square\) denote a perfect square.
